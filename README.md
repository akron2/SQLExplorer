# SQLExplorer

Кроссплатформенный настольный SQL-клиент для Oracle и PostgreSQL. Текущая версия — первый рабочий вертикальный срез: редактор Monaco, независимые SQL-вкладки, реальные подключения к обеим СУБД, порционная таблица результатов, отмена, ручные транзакции, метаданные, подсказки и восстановление рабочей области.

Проектные решения находятся в [docs/architecture.md](docs/architecture.md), фактический статус реализации — в [docs/implementation-status.md](docs/implementation-status.md).

## Быстрый запуск на Windows

В проекте закреплён Node.js 24.21 LTS. Проверенная локальная копия находится в `.local/toolchains` и автоматически используется скриптом:

```powershell
.\scripts\dev.ps1
```

Для первого запуска после чистого клонирования:

```powershell
npm install
npm start
```

`npm install` скачивает проверяемый Electron runtime. Системный Node должен соответствовать `.node-version`.

npm run verify        # lint, TypeScript, модульные тесты

## Линейные окончания (EOL) и чистый Git

Добавлен `.gitattributes`, который принудительно хранит текстовые файлы с `LF`, чтобы не ловить шум от `LF -> CRLF` при коммитах на Windows.

После изменения `.gitattributes` можно переиндексировать файлы и нормализовать истории концовок:

```powershell
git rm --cached -r .
git reset --hard
```

Windows-сборка создаётся в `out/release/SQLExplorer-win32-x64`. В локальном окружении её можно запустить с тестовыми профилями так:

```powershell
.\scripts\run-packaged.ps1
```

Локальные пароли находятся только в `.local/oracle` и `.local/postgres`; каталог исключён из Git и из приложения при упаковке.

## Что уже работает

- Один смонтированный Monaco Editor независимо от числа скрытых вкладок; модели создаются лениво.
- Выполнение выделения или текущего SQL-выражения по `F8`/`Ctrl+Enter`.
- Oracle через `node-oracledb` Thin и PostgreSQL через `pg`/`pg-cursor` в отдельном worker thread.
- Закреплённая сессия и ручный Commit/Rollback для каждой вкладки.
- Отмена активных запросов, порции до 1000 строк и явный `NULL`.
- Дерево объектов и контекстные подсказки колонок по алиасу.
- CSV, копирование, светлая/тёмная тема и SQLite-восстановление рабочей области.
- Проверочный режим `--perf-documents=100` и запись метрик первых кадров/восстановления окна.

## Текущие границы

Графический редактор профилей подключения, bind-параметры, открытие/сохранение SQL-файлов, постоянная история запросов и выбранный промышленный движок автодополнения ещё не входят в этот срез. Двойной щелчок по упакованному приложению не переносит локальные тестовые секреты; для разработки используется `run-packaged.ps1`.
