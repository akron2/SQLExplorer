# PostgreSQL для проверки SQLExplorer

Дата: 2026-09-09. Статус: отдельная учебная база создана; подключение драйвера SQLExplorer и основные сценарии проверены.

## Назначение и разрешение

Пользователь уточнил, что контейнер `confluence-postgres` относится к другому проекту, но является тестовым и его можно использовать для SQLExplorer. Название проекта не означает запрет на использование. Новый экземпляр PostgreSQL для начала проверок не нужен.

Для приложения создана отдельная база `sqlexplorer_dev` с ролью `sqlx_dev` в том же тестовом сервере. Схема содержит только вымышленные учебные объекты из [seed.sql](../infra/postgres/seed.sql). База `confluence` и её объекты при создании стенда не изменялись.

## Проверенные сведения

| Параметр | Значение |
|---|---|
| Контейнер | `confluence-postgres` |
| Образ | `postgres:10.23-bullseye` |
| Фактическая версия | PostgreSQL 10.23, Debian 10.23-1.pgdg110+1, x86_64 |
| Доступ с Windows | Опубликован `127.0.0.1:5432` |
| Базы | `confluence`, `postgres`; без шаблонных |
| Кодировка | UTF8 |
| Таблицы `public` | 126 |
| Таблицы `pg_catalog` | 62 |
| Таблицы `information_schema` | 7 |
| Том данных | `confluence_postgres10_data` |
| Каталог внутри контейнера | `/var/lib/postgresql/data` |

Хранилище Docker находится на D:, как зафиксировано в [описании окружения Oracle](oracle-test-environment.md). Перенос или пересоздание этого контейнера не выполнялись.

## Выполненная проверка

Через установленный в контейнере `psql` под локальной учётной записью ОС `postgres` прочитаны версия сервера, список баз, количество таблиц и несколько имён объектов. Это подтверждает доступность сервера и метаданных. Значения бизнес-строк не запрашивались, схема и данные не изменялись.

Через `pg` и `pg-cursor` с Windows проверены вход обычной ролью приложения, чтение метаданных, порционная выдача, откат DML и отмена `pg_sleep`. Реквизиты находятся в `.local/postgres/connection.json`, исключённом из Git.

PostgreSQL 10.23 входит в доступный тестовый контур. Минимальные и максимальные поддерживаемые версии SQLExplorer пока не утверждены; совместимость кандидатов автодополнения с каталогами этой версии проверяется отдельно.
