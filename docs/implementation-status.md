# Статус реализации SQLExplorer

Дата: 2026-09-09. Версия приложения: 0.1.0.

## Выполнено

Первый рабочий срез реализован на Electron 44, React 19, TypeScript 6, Monaco 0.56 и react-data-grid. Исходники, воспроизводимый lock-файл, тесты и Windows x64 package находятся в этом проекте.

Архитектурные границы соблюдены:

- renderer изолирован (`sandbox`, `contextIsolation`, без Node integration) и использует узкий preload API;
- соединения, пароли, драйверы, сессии и курсоры не передаются в renderer;
- драйверы выполняются в отдельном worker thread;
- сессия закрепляется за документом, запросы автоматически не повторяются;
- скрытые документы не держат смонтированные редакторы или таблицы;
- локальная рабочая область и метрики хранятся в SQLite.

## Фактические проверки

| Проверка | Результат |
|---|---|
| ESLint + строгий TypeScript | проходит |
| Модульные тесты | 13 тестов проходят |
| Browser E2E | Oracle/PostgreSQL-контексты и 100 документов проходят |
| Oracle 21c XE | connect, metadata, paging, rollback, cancel проходят |
| PostgreSQL 10.23 | connect, metadata, paging, rollback, cancel проходят |
| Electron shell | реальные запросы к обеим БД проходят |
| Electron, 100 документов | один editor/model, восстановление окна проходит |
| Windows x64 package | создаётся и запускается из ASAR |
| `npm audit` | 0 известных уязвимостей |

Интеграционный тест использует только учебные схемы. Проверочные вставки выполняются внутри закреплённых транзакций и откатываются; итоговое отсутствие строк с контрольным ключом проверяется запросом.
