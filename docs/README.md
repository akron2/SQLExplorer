# SQLExplorer: проектные документы

Дата актуализации: 2026-09-13. Статус: базовые рабочие сценарии, каталог объектов с контекстным автодополнением, просмотр и сохранение LOB и экспорт результатов в Excel реализованы и проверены.

SQLExplorer — кроссплатформенный настольный клиент для Oracle и PostgreSQL с современным интерфейсом. Ориентир по удобству — PL/SQL Developer. Основной проблемный сценарий: восстановление главного окна при большом числе открытых внутренних рабочих окон.

## Что зафиксировано

- Oracle и PostgreSQL входят в первую версию; вкладки с разными СУБД могут быть открыты одновременно.
- Oracle Thin и несколько конфигураций Thick работают одновременно; поддержаны TNS alias, custom connect string и парольный SYSDBA.
- Профили управляются из UI, а пароли сохраняются через Electron safeStorage.
- Состояние профиля отделено от состояния физической сессии; периодические ping и скрытый retry SQL исключены.
- SQL-файлы открываются и сохраняются через видимый UI с сохранением кодировки, BOM и EOL.
- Приложение должно быть кроссплатформенным и иметь современный компактный интерфейс.
- Скрытые документы сохраняют состояние, но не должны добавлять работу по отрисовке при восстановлении окна.
- Рабочий стек: Electron, TypeScript, React, Monaco, react-data-grid, node-oracledb, pg/pg-cursor, ExcelJS и SQLite.
- Тяжёлые значения (LOB) хранятся в процессе соединения: renderer получает маркеры, просмотр и сохранение идут порциями, PostgreSQL-значения ограничены подтверждаемым бюджетом.
- Автодополнение строится на собственном индексированном каталоге объектов; движок подключается как анализатор контекста, кандидаты оцениваются на корпусе ([решение](autocompletion-architecture.md)).

## Реализация

Базовая реализация работает: Electron/React/TypeScript, Monaco, react-data-grid, SQLite и изолированные UtilityProcess для PostgreSQL и Oracle Thin/Thick. Текущий проверенный состав и команды находятся в [статусе реализации](implementation-status.md).

Для тестов доступны Oracle 21c XE с Instant Client 19.32 и отдельная учебная база PostgreSQL 10.23. Детали и ограничения стендов находятся в соответствующих документах. Выполненный Windows-срез, оставшиеся проверки производительности, совместимости и платформ также разделены между [статусом](implementation-status.md) и [бэклогом](backlog.md).
